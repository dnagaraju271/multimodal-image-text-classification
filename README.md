# Multi-Modal Classification and Analysis of Images and Text using Deep Learning

## Project Objective
Combine visual features extracted from images using CNNs and textual features extracted from captions using LSTM/BiLSTM models.

## Planned Models
1. Image-only CNN
2. Text-only LSTM/BiLSTM
3. Multimodal CNN + LSTM fusion

## Dataset
Planned dataset: MS COCO 2017.

Dataset preparation and final class selection will be documented here.
